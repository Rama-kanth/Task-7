 SQL in Python: Data Analysis with Bar and Pie Charts
This repository demonstrates how to use SQL queries within Python for data analysis and visualization. It includes examples of querying data using SQL and generating bar and pie charts using Python libraries.

 Features
Execute SQL queries using sqlite3 

Load data into Pandas DataFrames

Visualize results with bar and pie charts using matplotlib

Easily customizable for your own datasets
Requirements:
Make sure you have the following Python libraries installed:

pip install pandas matplotlib sqlite3
